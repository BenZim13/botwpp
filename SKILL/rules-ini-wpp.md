# WhatsApp Bot Orchestrator (Vercel + Supabase + Gemini)

Guía metodológica y generador de componentes para construir un bot conversacional en WhatsApp sin costos fijos de servidor, utilizando WhatsApp Cloud API de Meta, funciones serverless en Vercel, persistencia relacional en Supabase y procesamiento de lenguaje natural con Google Gemini.

## Flujo de Trabajo Operativo
1. Fase 1: Variables de entorno requeridas en Vercel.
2. Fase 2: Ejecución de esquema SQL en Supabase.
3. Fase 3: Generación del endpoint de webhook en Node.js/TypeScript.
4. Fase 4: Suscripción en Meta for Developers.
